    Carregar planilha atualizada

    Envie o .xlsx do formulário de mecanização com as linhas novas. A leitura acontece no seu navegador; só os dados já tratados vão para o servidor.

    Arraste a planilha aqui ou clique para escolher

    Somente a aba dados é lida. A estrutura de colunas deve ser a mesma.

    Situação dos dados

    De onde o painel está lendo agora.

    Como funciona

    1. Exporte a planilha do formulário mantendo a aba dados e as mesmas colunas — só acrescente linhas.
    2. Envie o arquivo aqui. O painel compara com os dados atuais e mostra quantos registros entraram.
    3. Publicar para todos grava data/mecanizacao.json no servidor (precisa do PHP ativo, como no XAMPP) e todo mundo passa a ver os dados novos. A versão anterior fica guardada em data/mecanizacao-anterior.json.
    4. Usar só neste navegador guarda no seu navegador, sem tocar no servidor — serve para conferir antes de publicar.
    5. As abas Inserções por pessoa / por dia / por mês e Culturas saem da mesma aba dados e só aparecem com a senha — elas nomeiam quem lançou cada linha. Publicar uma planilha nova atualiza as quatro junto com o resto do painel.
    6. O upload troca apenas o ano corrente. Os exercícios encerrados (2023 a 2025) ficam em js/dados-mecanizacao-historico.js e não são afetados. Para refazê-los, rode python tools/gerar_historico_mecanizacao.py.

    Atenção: o exercício de cada linha é o da planilha em que ela foi lançada — por isso o total de um período bate com o SOMA do Excel daquela planilha, mesmo quando a vistoria foi feita no ano anterior. Já o mês nos gráficos é o da Data da Vistoria; quando essa data é impossível (ano digitado errado ou data futura), vale a data de lançamento e a linha aparece destacada na listagem.
